# Security Policy

Brickwall Consultancy is a cybersecurity firm; we hold this repository to the standard we sell.

## Reporting a vulnerability

- **Preferred:** use GitHub's [private vulnerability reporting](../../security/advisories/new) on this repository.
- Email: `security@brickwallconsult.com`

Please do not open public issues for security problems.

## Scope notes

This repository contains compliance *content* (OSCAL JSON and documentation), not running software. Relevant reports include:

- Incorrect control encodings that could cause a consumer to under-comply with the law
- Malicious or tampered catalog content
- Supply-chain issues in CI workflows

We aim to acknowledge reports within 72 hours.
